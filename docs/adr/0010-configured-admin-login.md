# 可信网络中的管理员与本地数据

2026-10-30 用户确认：管理台只用于可信局域网或 VPN，使用明文 HTTP 简化部署。管理员账号和密码在服务器配置中维护，所有管理员共用学校账号及权限，不做注册、网页管理员管理或账号归属划分。普通密码在启动时转为内存哈希，也兼容已有哈希；修改配置后重启，登录会话固定十二小时，退出不停止任务。

学校密码和 Cookie 在本地明文保存，程序不额外强制收紧文件权限。能访问配置、数据目录或 HTTP 流量的人可能取得凭据；管理员登录和 CSRF 防护不能加密传输，因此不部署到公网。访问学校始终使用校验证书的 HTTPS。

日常操作见 [Web 指南](../web.md)，业务边界见[规则](../requirements.md)。旧部署方案通过 Git 查看。

# 所有阶段保留独立查询所有者和邮件发送线程

2026-11-04 的 [ADR-0013](0013-versioned-waits-and-captcha-preparation.md) 补充版本通知与绝对等待，并将生产模式验证码预取交给独占主会话的临时任务；本文关于两个查询所有者、邮件发送和唯一任务写入者的决定继续适用。

2026-11-03 用户确认普通期、慢抢期和快抢期统一采用每账号主线程、活动列表只读线程、历史列表只读线程和可选邮件线程。两条查询线程各自拥有会话、在途请求和重试；主线程负责认证、消费可靠快照、验证码、串行提交及任务状态写入，所需快照不可用时跨轮等待。移除主线程同步查询兜底，避免错误恢复时反复交接端点、关闭健康读者或扩大停顿；阶段切换只调整参数，认证失效才停止读者并重新认证，学校明确要求的等待仍共同遵守。

预热、候选出现和提交后核对均向历史所有者请求刷新。缺席核对使用本次核对开始后发起的两个来源查询，不能反复消费同一份缺席记录来累计三次；明确成功证据仍可提前确认。代价是无法保证开放前主会话的历史查询连接预热，普通期也维持两个只读会话，冷启动及查询故障时须等到可靠快照才继续。

主线程在触发时决定邮件类型、去重并生成不可变正文，邮件线程只发送，结果回到主线程保存；取消开抢期告警延后，五分钟故障阈值保持。退出最多等待邮件队列五秒，尚未完成的发送可能中止且不自动补发。调度、兼容开关与验收边界见[使用指南](../usage.md#开抢与拥塞恢复)和[本轮验收](../acceptance/2026-11-03-unified-workers.md)。

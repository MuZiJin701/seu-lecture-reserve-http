# 当前预约清单复用引擎查询与精简本地快照

2026-10-30 控制台改版澄清第二轮，用户确认网页展示学校账号全部有效、尚未结束的预约，数据复用预约引擎已有学校查询，并只保存展示所需的精简本地快照；浏览网页不增加学校登录或查询，也不保存完整个人历史。相比网页直接查询学校，该方案保持预约引擎掌握学校会话和请求节奏，代价是网页只能显示最近成功同步的数据，而不能承诺实时性。

清单展示同步时间；账号停止或查询失败时保留上次有效数据并标注状态，首次尚未查询显示“尚未同步”。待确认提交和时间占位单列，不作为已预约；展示快照只用于观察，不成为预约结果核对或重复提交判断的新证据。当前预约清单也不等同于计入选听目标的待参加计划，详见[术语](../../GLOSSARY.md)及[控制台改版需求](../console-redesign.md)。

用户在两轮澄清及 Logo 补充后明确要求实施，方案据此接受。精简快照和清单展示已实现，[离线验收](../acceptance/2026-10-30-console-redesign.md)覆盖保留有效预约、剔除已结束或取消、查询失败保留上次快照及待确认单列；真实学校运行另行验收。

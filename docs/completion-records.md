# 选听完成记录接口调查

证据采集于 2026-10-16；2026-10-18 补充核对非空讲座列表；2026-10-25 补充真实提交/取消与候选可用性算法（见文末）。本文保留接口证据与未知边界，当前统计选择见[目标统计与冲突](requirements.md#目标统计与冲突)，运行和验收见[使用指南](usage.md)。

## 证据来源

研究生院的[2026 级春季博士选课须知](https://seugs.seu.edu.cn/2026/0306/c35055a557360/page.htm)、[2024—2025 秋季选课通知](https://seugs.seu.edu.cn/_upload/article/files/8b/f9/4e574f304b2a82f109c34072f59a/fd2fc991-ad03-44ed-8cd3-18242d0264e6.pdf)及物理学院的[培养环节说明](https://physics.seu.edu.cn/2026/0625/c23174a573883/pagem.htm)支持调查时的八场及三类目标，但不能证明全部培养方案或最新政策均相同，也不说明接口如何证明考核认可。

调查时在已认证的只读会话中核对了学校 [hdyy.js](https://ehall.seu.edu.cn/gsapp/sys/yddjzxxtjappseu/modules/hdyy/hdyy.js)、[页面模板](https://ehall.seu.edu.cn/gsapp/sys/yddjzxxtjappseu/modules/hdyy/hdyyIndexPage.html)和 [hdyyBS.js](https://ehall.seu.edu.cn/gsapp/sys/yddjzxxtjappseu/modules/hdyy/hdyyBS.js)。匿名访问可能被网关拦截，以下语义来自当时版本：

| 字段或行为 | 证据及含义 |
| --- | --- |
| `queryMyActivityList.do` / `wdhdList` | “我的活动”入口与列表；前端发送 JSON `param` |
| `HD_WID` | 预约对应的活动 ID，区别于预约记录自身的 `WID` |
| `SFDK='1'` | 已打卡，不能证明学院考核认可 |
| `SFWY='1'` | 已违约，前端显示优先于打卡 |
| `FBZT='-1'` | 活动取消，不能推断个人取消预约的全部记录方式 |
| “已预约”筛选 | 前端查询 `FBZT='1'`，另排除打卡或违约记录 |
| `SFPJ` / `SFXSPJ` / `SFXSYQFK` | 评价状态、评价按钮、反馈按钮；未发现与考核认可等价的规则 |
| `count` | 通知公告未读数，不能当讲座总数 |

`hdyyBS.js` 仅声明 `/modules/hdyy.do` 模型地址，没有证明存在独立的考核认可接口。用户已接受“学校已打卡、未违约、未取消”的本地统计口径，没有继续追查其他系统。

## 只读样本结果

2026-10-16 真实认证和 `Client.mine()` 成功，验证仅输出字段名与布尔结果；没有保存个人行、身份、票据或 Cookie。

- 样本包含 `JZXL`、`JZXL_DISPLAY`、`JZMC`、`JZSJ`、`HDJSSJ`、`SFDK`、`SFWY`、`DKSJ`、`SFPJ` 等字段。
- 没有显式总数或分页元数据；单独查询 `param={"SFDK":"1"}` 的活动 ID 集合，与默认列表按相同条件筛选的集合一致。
- 样本打卡和违约标记均为已知 `0`／`1`，类别存在，未发现重复活动 ID；不在本文记录个人次数或字段值。
- 当时未出现旧候选解析器依赖的 `HDLX_DISPLAY`。2026-10-18 又核对了六条非空活动列表，修正为真实字段、预约时间窗及明确的线上线下标记，见[数据契约](usage.md#当前业务数据契约与限制)。

## 客户端边界

[`Client.mine`](../seu_reserve/client.py)默认请求 `param='{}'`，校验数组、行类型及响应已提供的总数。没有总数时仍不能证明全历史完整；当前样本一致不排除跨学期截断或其他渠道遗漏。

[`progress`](../seu_reserve/model.py)处理已有记录，候选由 `Lecture.read` 另行处理；两类响应不能直接套用同一解析器。只统计四类系列讲座与沙龙，按 ID 去重；测试活动及购票公告跳过；所选已结束记录尚无打卡或违约结论时等待，未知类别、状态或矛盾重复记录阻止新增。

当前规则由用户确认，不代表所有培养方案统一要求；评价、预期反馈以及其他学分系统不能作为本项目的完成证明。本地目标统计与学校最终认定分别判断。

截至 2026-10-16，历史学校操作仅为认证、只读查询和静态文件读取，未据此验收预约、取消、签到、评价或反馈。真实预约、其他学期完整性及新响应格式当时仍待验证；个人原始响应不进入仓库、日志或研究附件。

## 2026-10-25 补充

- **候选可用性**：改用学校前端 `hdyy.js` 同款算法——`queryActivityList.do` 的 `hdlbList` 按 `HD_WID` 合并 `hdrsList` 的 `YYRS`（已约人数），与行内 `HDZRS`（总人数）比较判满员；用响应中的服务器时间 `xtdqsj` 判未开放/已结束；`appiontCheck.do` 因对任意参数几乎都返回 `code=0` 而移除，不再作为资格判定。
- **真实提交/取消**：2026-10-25 用 HTTP 版对购票公告（非目标测试活动）真实提交成功（`addReservation.do` 返回 `code=0`），按 `HD_WID` 在“我的活动”确认，随后 `deleteReservation.do` 取消并复核消失；本机与服务器各验证一次。目标系列讲座的真实预约与抢约命中率仍待验证。
- **目标口径**：沙龙按 2026-10-25 确认计入选听总场次、不替代法律/艺术/心理健康必需类别；测试活动与购票公告不预约、不计数。

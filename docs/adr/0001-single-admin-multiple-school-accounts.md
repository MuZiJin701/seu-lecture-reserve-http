# 单管理员统一管理多个学校账号

2026-10-30 需求澄清第一轮，用户选择由本人独占使用网页管理台，统一管理多个学校账号，而非建设多人自助平台。学校账号是预约与进度的独立主体，管理员是集中操作这些账号的人；据此采用单管理员的权限与数据归属边界，避免引入尚无需求的用户注册、账号归属转移和跨用户授权体系。第四轮明确 10 个账号仅为并发验收目标，不设启动硬上限。

第二轮曾确认采用独立于学校账号的管理员密码，登录配置保存在服务器 `.env`，不开放注册；后续 [ADR-0008](0008-trusted-environment-http-no-login.md) 撤回了管理员登录与公网 HTTPS，管理台改为可信环境中的明文 HTTP，不再区分操作者身份，但“仅本人或少数人使用”的范围前提不变。学校凭据保存方式以第四轮 [ADR-0005](0005-local-plaintext-school-credentials.md) 为准；本决策已在 Web 改造中实现；离线验证与真实验收分开记录，完整需求见[改造澄清记录](../requirements.md#多账号与-web-改造)。

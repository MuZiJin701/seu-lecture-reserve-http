# 学校账号身份唯一且不可修改

2026-10-30 需求澄清第三轮，用户选择以一卡通号作为学校账号的唯一身份，添加后仅允许修改显示名称、密码及选项，不允许把已有账号改成另一一卡通号。相比原地更换身份，此边界避免将旧任务、待确认保护或信任 Cookie 错误移给另一个学校账号；管理台内注册和启动仍须防止同一账号重复启动，但跨进程身份锁已移除，同一账号并发登录已实测可行，见 [ADR-0009](0009-concurrent-sessions-and-locks.md)。

需要更换学校账号时，先按删除保护完成旧账号核对，再新增另一账号。本决策已实现，离线证据见 [HTTPS 版本离线验收](../acceptance/2026-10-30-web-offline.md)，完整需求见[改造澄清记录](../requirements.md#多账号与-web-改造)。

# 2026-10-30 多账号与 Web 离线验收

> 注：本文记录 HTTPS＋管理员登录＋文件权限限定版本的离线验收。现行 HTTP 简化见[本轮 HTTP 简化验收](2026-10-30-http-console.md)与 [ADR-0008](../adr/0008-trusted-environment-http-no-login.md)、[ADR-0009](../adr/0009-concurrent-sessions-and-locks.md)；原有观测数字保持原样，仅作历史证据。

[需求](../requirements.md#多账号与-web-改造) · [部署指南](../web.md) · [验收总表](../usage.md#验收记录)

本轮实现 FastAPI＋Uvicorn 直接 HTTPS 管理台、SQLite 账号目录和每账号独立工作进程。以下证据使用 Windows、Python 3.12、锁定依赖、临时构造配置与账号；没有加载真实 `.env`，没有连接学校、提交真实预约或发送真实邮件。

新增 `tests/test_web.py` 覆盖管理员认证、Secure／HttpOnly／SameSite Cookie、CSRF／来源校验、登录失败冷却、有界请求体、校验错误不回显密码、账号唯一和身份不可修改、配置安全重启、删除保护、按账号收件人路由及启用邮件但配置无效时拒绝启动。

实际 spawn 十个独立构造工作进程，核对独立 PID、Task 账号归属和锁；分别等待短信输入，拒绝跨账号及过期挑战。第十一个进程在原十个仍运行时成功启动，证明没有十账号硬上限；停止一个账号，其余进程继续。此检查验证进程隔离，不执行学校请求。

异常退出检查涵盖三次／五秒重启预算、十分钟稳定重置、不可恢复错误停止、关闭恢复意图以及目录不可用时仍回收其他子进程。迁移检查涵盖原文件保留、待确认恢复、复制失败回滚、相同数据根目录的旧任务须导入、CLI／Web 共享身份锁与迁移后旧入口保护。Cookie 无归属或异账号时不复用，过期回退保留。

另用现有预约引擎与构造 School 响应运行短信发送和验证码交互，核对当前挑战路由、日志不含验证码；停止请求发生在提交前时保留原扫描检查点，不提交。监督器异常告警使用替代 Mailer，检查按账号收件及每任务告警额度，无真实 SMTP。

直接 HTTPS 检查启动真实 Uvicorn、本地临时证书及客户端，客户端信任该证书并校验地址，完成登录和账号接口往返，未关闭证书校验。缺少 TLS 配置拒绝启动。

## OCR 资源测量

Windows 主机、32 个逻辑 CPU、约 32 GiB 内存（测量前可用约 17 GiB），同时启动十个进程，各加载当前锁定版本 ddddocr／ONNX 模型，并分别识别五张构造空白 100×40 PNG：

| 指标 | 观测值 |
| --- | --- |
| 十进程模型加载后工作集总和 | 982.2 MiB |
| 最大单进程加载峰值工作集 | 105.9 MiB |
| 各进程模型加载耗时 | 约 0.70–0.80 秒 |
| 各进程五次识别的中位耗时 | 约 0.006–0.023 秒 |
| 此次批次总耗时 | 约 1.26 秒 |

该测量只说明本机进程／模型的基础开销，不代表真实验证码准确率、持续并发、HTTP 会话峰值或 Linux 服务器容量；生产内存还需为管理服务、网络会话和系统留余量。

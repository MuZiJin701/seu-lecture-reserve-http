# 使用与验收

首版为 Python 3.12 的单账号同步客户端。实现依据 [Spec #1](https://github.com/MuZiJin701/seu-lecture-reserve-http/issues/1)，不依赖浏览器。

## 安装与离线检查

```bash
uv sync --locked
uv run --locked mypy seu_reserve
uv run --locked pytest
uv run --locked seu-reserve --help
```

依赖安装到项目隔离环境；OCR 使用 ddddocr，模型随依赖包提供。首次安装包含 ONNX、图像依赖和模型，下载量较大。
测试只使用构造的学校响应、临时时间/文件、人工输入和邮件替身，不加载真实账号配置，不访问学校，不发送真实邮件。

## 配置与凭据

```bash
cp -n .env.example .env
chmod 600 .env
# 编辑 .env，填写登录信息、筛选和邮件配置
uv run --locked seu-reserve --status
```

登录、筛选、状态目录和邮件统一放入 [.env.example](../.env.example) 对应的 `.env` 文件，程序默认自动读取**当前工作目录**的 `.env`，不向上搜索其他目录。
在其他目录运行时，用 `--config /项目目录/.env` 明确指定文件。显式指定的文件不存在会报错，不回退读取其他文件。
状态目录相对于所选 `.env` 所在目录；默认名称为 `state`。进程环境变量优先于文件，不会把文件内容写回全局进程环境。

| 配置项 | 含义 |
| --- | --- |
| `SEU_CARD_NUMBER` / `SEU_PASSWORD` | 一卡通号 / 密码，与旧项目命名一致 |
| `SEU_PREFERRED_LECTURES` | 完整标题列表，`'[]'` 表示不限标题 |
| `SEU_REQUIRED_CATEGORIES` | 类别 JSON 数组，省略时使用已确认的五类及顺序，不能是空数组 |
| `SEU_PREFERRED_CAMPUS` | 允许的线下校区 JSON 数组，`'[]'` 表示不约线下 |
| `SEU_ENABLE_ONLINE` / `SEU_ENABLE_OFFLINE` | 是否允许线上 / 线下，值为 `true` 或 `false` |
| `SEU_STATE_DIR` | 任务状态和日志目录，默认 `state` |

列表是 JSON 数组，外层用单引号，例如 `SEU_PREFERRED_CAMPUS='["无锡校区"]'`。
标题完整匹配仍受其他筛选及冲突规则约束；线上识别来自明确业务字段，不从标题猜测。
密码等字符串含空格、`#`、`=` 或 `$` 时可以按示例用引号包裹。`${...}` 原样保留，不做变量展开；`.env` 由 Python 读取，不需要也不要作为 shell 脚本执行。
真实 `.env` 和 `.env.*` 已被 Git 忽略，仅提交不含凭据的 `.env.example`。

为保留此前的使用方式，也接受 `SEU_USERNAME`；同一来源同时有它和 `SEU_CARD_NUMBER` 时后者优先，任何进程环境中的账号设置都优先于文件中的账号设置。
未填写登录信息时仍可在交互终端隐藏输入；非交互运行缺少凭据时直接报错。

正式预约还需在同一 `.env` 中填写邮件配置：

| 变量 | 含义 |
| --- | --- |
| `SMTP_HOST` | SMTP TLS 主机 |
| `SMTP_PORT` | 隐式 TLS 端口，默认 465 |
| `MAIL_FROM` / `MAIL_TO` | 发件人 / 收件人 |
| `SMTP_USERNAME` / `SMTP_PASSWORD` | SMTP 认证，需成对提供；允许无需认证的 TLS 中继 |

首版使用 SMTP 隐式 TLS，不提供明文连接或 STARTTLS 模式。邮件只包含固定事件、时间和处理提示，不包含学校账号、标题、验证码或个人活动记录。

从此前 TOML 方式迁移时，按新 `.env.example` 填入对应字段即可；TOML 配置入口已移除，已有个人 `config.local.toml` 不会被删除。
旧 Playwright 项目的浏览器专用超时参数不适用于本项目，不要原样复制整个旧 `.env`；正常轮询仍为已确认的 10 秒。

## 先做只读检查

```bash
uv run --locked seu-reserve --check
```

该命令认证后查询列表、我的活动并获取校验验证码图片，不提交或取消预约，不创建预约任务，也不发送邮件。
成功退出码为 0，终端显示 `event=read_only_complete`；失败退出码为 1。认证需要短信时仍须人工处理。
此检查验证接口读取及图片解码，不代表活动字段映射、冲突数据完整性、OCR 准确率或真实预约已验收。

## 运行和恢复

```bash
uv run --locked seu-reserve
```

此命令会对符合条件的候选提交真实预约。默认每 10 秒查询，异常时退避（20、40、80 秒，最多 300 秒），学校明确的 Retry-After 优先。
类别配置顺序优先，其次线上优先、开场较早优先。冲突检查包含首尾相接；已有预约状态或时间不完整时停止本轮提交。

每次提交前先原子保存待确认活动 ID。超时或响应无法解释时先查询原提交，期间不提交第二场；持续不明确时通知并等待人工处理。
异常等待截止时间会一并持久化，重启后先等完剩余时间，避免绕过学校限流。过期冷却记录会清理。
等待时按回车只会重新查询，不会把用户按键当作“预约失败”的证据。不要手工删除待确认任务来绕过保护。
明确验证码错误时最多重新取图识别三次；仍失败冷却该场五分钟，再尝试其他候选。

同一状态目录加进程锁，只允许一个实例运行。重启恢复原任务；成功任务再次启动立即结束。
需要再预约另一场时，显式启动新任务：

```bash
uv run --locked seu-reserve --new-task
```

仅允许替换已完成任务；待确认或仍在扫描的任务不能用此参数重置。状态损坏或账号不匹配时停止，避免覆盖旧任务。
程序使用私有权限的任务文件、原子替换及持久化写入；任务只保存恢复必需的数据，不保存账号密码或完整业务记录。
状态目录内的 `events.log` 保存脱敏事件；邮件失败也会记录，不会改变已确认成功的任务。

## 人工认证

需要短信意味着认证未通过，此时不做业务查询或预约。通过保留的 SSH 交互终端输入 `send` 主动发送/重发短信，再输入六位验证码。
验证码使用与当前学校前端相同的 RSA 加密字段提交；不会后台自动反复发送。错误或过期后可再次主动发送，等待无固定截止时间。
未知认证挑战保持等待并显示固定提示；明确凭据错误或账号受限时停止自动登录尝试。

首版人工输入依赖交互终端；运行时应保留 SSH 终端，或使用已有的终端会话管理工具以便重新连接。
无终端而需要人工输入时会安全退出，保留任务供重新启动恢复；首版尚未提供后台进程的远程验证码输入通道。
Ctrl+C 退出码为 130，不会自动取消已有预约。

## 当前业务数据契约与限制

认证和业务接口来自交接探针；短信发送及加密字段另经学校公开 CAS 前端代码核对。
本次没有真实凭据，未读取受保护的实际活动响应，也未调用预约提交。以下活动字段是当前显式支持的输入契约，仍需用真实脱敏响应核实：

| 信息 | 当前支持的字段及值 |
| --- | --- |
| 活动 ID | `HD_WID` 或 `WID`，非空字符串 |
| 标题 / 类别 | `HDMC` / `HDLX_DISPLAY` |
| 起止时间 | `KSSJ` / `JSSJ`，或 `HDKSSJ` / `HDJSSJ` |
| 时间格式 | `YYYY-MM-DD HH:MM:SS`、`YYYY-MM-DD HH:MM`、`YYYY/MM/DD/HH:MM:SS`，按 Asia/Shanghai 解释 |
| 线上标记 / 地点 | `IS_ONLINE` 布尔值 / `JZDD` 字符串 |
| 可预约状态 | `YYZT` 等于 `预约` |
| 已预约状态 | `YYZT` 为 `已预约`、`预约成功` 或 `取消预约` |
| 非有效预约状态 | `YYZT` 为 `已取消`、`取消成功` 或 `未预约` |

未知线上标记或关键字段阻止提交；未知已有预约状态、损坏时间或总数不匹配也阻止提交。不会猜测数字状态码或从标题认定线上。
当前列表接口支持完整数组；返回分页对象或总数不符时拒绝，不把当前页当作全部已有预约。适配新的实际字段或分页协议前需增加入口回归场景。
未知提交响应按结果待确认处理，仅明确的验证码错误或不可预约响应允许继续其他动作。

# 2026-10-30 管理员登录与单页控制台离线验收

本轮实现依据[两轮已确认需求](../console-redesign.md)、[ADR-0010](../adr/0010-configured-admin-login.md) 与 [ADR-0011](../adr/0011-local-reservation-display-snapshot.md)。旧 [HTTP 简化验收](2026-10-30-http-console.md) 的匿名访问结论仅描述当时版本，当前学校数据 API 要求管理员认证。

## 实现与检查

- `.env` 的 `SEU_WEB_ADMINS` 可直接保存多个用户名和密码，也兼容已有哈希；普通密码在启动时派生为内存哈希，不改写配置。空配置、空密码、非字符串、重复用户名或无效哈希拒绝启动；`--hash-password` 为可选工具，不读取学校配置。标准库 PBKDF2-HMAC-SHA256、600000 次迭代、随机盐，无新增依赖。
- 登录固定 12 小时、多浏览器并存、退出仅撤销当前会话；重启丢弃内存会话。登录失败按来源与全局上限限速（成功不占预算并清除来源记录，超限 429 带 `Retry-After`），学校 API 要求登录与写操作 CSRF，原 Origin / JSON / 请求大小限制保留。
- 管理界面为浅色自然静态背景、磨砂卡片、黑色主按钮，无左侧导航或宣传区。页面名称为“东南大学素养讲座预约控制台”，学校账号在界面简称“账号”。Python / Pillow 生成纯图案书页与时钟 Logo 和静态风景，全部资源本地提供。
- 四个账号操作按钮等宽、等高（54px），主操作为深色、辅助操作为描边、删除操作为红色；放大管理员名称、退出登录、账号名称和关键状态。手机顶部允许换行，修复管理页最小宽度及登录卡片的窄屏溢出。
- 卡片末尾始终有新增入口；桌面右侧、手机下方显示详情。手动保存、未保存修改的页面内确认框、自动刷新保留草稿与配置冲突提示均已用浏览器验证。
- 数据库向后兼容增加配置 `revision`；旧版本保存先拒绝，不停止当前工作进程。已纳管账号统一应用隐藏策略，旧单账号 CLI 配置能力保持。
- 当前预约仅保存活动 ID、标题、类别、地点 / 线上方式、举办起止时间、预约状态及快照时间；覆盖学校全部有效未结束预约，不按选听计划去重舍弃重叠或沙龙预约。待确认与占位单列，页面访问不增加学校查询，失败保留上次快照。

## 后续审查修复（2026-10-30）

实施完成后按只读审查结论修复了下列问题，均为离线可验证范围；真实学校、SMTP、Linux 与长期运行仍未验证：

- **外部 CLI 运行中的服务端互斥**：`Manager.start/stop/update` 原先只检查自身工作进程，CLI `--account` 持锁运行同一账号时仍可能返回成功——`stop` 报 200 却仍在运行、`update` 写入与 CLI 实际使用的配置分叉、`start` 触发最多三次无效重启并可能发出“连续异常退出”告警。现在三者与已有的删除一样在改动任何状态前检查账号 `task.lock`，被其他进程持有时返回 `state_in_use`（HTTP 409）；该原因不再消耗重启预算、不触发 `restart_exhausted` 或告警邮件，而是清除运行意图并显示“账号正由 CLI 运行”。前端仍按 2 秒状态禁用控件，服务端不再依赖该时间差。
- **登录限速只统计失败**：原实现把每次登录（含成功）写入尝试队列且成功后不清零，同一来源 1 分钟内第 6 次正确密码登录也会被拒，全局上限被失败尝试耗尽时所有管理员都被锁在 429 外。现在只记录失败尝试，成功登录清除该来源记录；超限 429 响应带 `Retry-After: 60`，便于客户端退避。
- **启动只派生一次管理员密码哈希**：`web.main()` 的配置校验和 `create_app()` 各自构造一次 `Administrators`，明文密码被 PBKDF2 派生两次（实测约 0.14 秒/次）。现在 `main()` 构造一次并注入，`create_app(..., administrators=...)` 复用同一实例。
- **账号库迁移可并发**：`revision` 列的 `ALTER TABLE` 在 Web 与 CLI 同时打开旧库时可能撞上 `duplicate column`；现在把该错误视为同一终态，不再让启动以通用配置错误失败。
- **`--account` 启动失败清理**：OCR 不可用时，首次启动新建的检查点目录与 `task.json` 会被清理，不再留下从未真正运行的任务。
- **前端**：点击当前已选卡片不再弹出“放弃未保存修改”确认。
- **文档**：Web 指南的登录限速、外部 CLI 与 API 说明，需求的登录限速与外部 CLI 规则，以及 ADR-0005 的历史注解已同步；`.env.example` 的空管理员样例与 Web 指南的“替换示例密码”措辞改为一致的“空列表会阻止启动，须先填写”。

新增回归覆盖：外部 CLI 持锁时启动/保存/停止/删除被拒绝且配置未被改写、`state_in_use` 不进入重启预算与告警、登录成功与失败的限速计数、429 的 `Retry-After`、`create_app` 注入、迁移重复列忽略、OCR 失败清理，以及本轮补充的快照陈旧标记、页面不触发学校请求、重启清会话、新建账号隐藏策略、输入校验、静态资源与展示字段映射。浏览器布局与未保存输入保护仍只有手工记录，未引入浏览器测试依赖。修复后完整离线测试 **692 通过、3 跳过**（较修复前 667 增加 25 条回归），mypy 12 个源文件通过，`node --check` 通过。

## 尚未验证

未修改真实管理员配置或部署 / 重启现有服务；首次使用直接在 `.env` 填写管理员账号和密码后重启，哈希命令可选。真实学校多账号、SMTP 送达、Linux systemd、真实开抢收益及长期运行未验证，既有单账号样本不能代替上述验收。HTTP 与本地明文凭据的已确认取舍仍存在，仅限可信局域网 / VPN。

预约清单的“线上 / 线下”取自活动记录的 `IS_ONLINE` 布尔或标题的 `【线上】`／`【线下】` 前缀；离线构造响应已覆盖两条来源，但真实“我的活动”样本是否提供这些字段尚未验证，缺失时界面显示“方式未提供”而不是猜测。桌面与手机布局、未保存输入保护仍以浏览器手工记录为准，仓库没有自动化浏览器测试。

密码派生实现依据 [Python hashlib](https://docs.python.org/3.12/library/hashlib.html#key-derivation) 与 [OWASP 密码存储建议](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)；HTTP Cookie 的约束见 [MDN Set-Cookie](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Set-Cookie)。

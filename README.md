# 东南大学素养讲座预约控制台

[English](README.en.md)

集中管理多个学校账号，按类别、校区和时间冲突自动筛选并预约讲座。提供中文网页和命令行入口，需要短信认证时由你完成。

**使用范围：可信局域网或 VPN。** 管理台使用明文 HTTP，学校密码和登录 Cookie 会明文保存在本地，请妥善保管配置和数据目录。程序访问学校时使用校验证书的 HTTPS。

## 安装与启动

准备 Python 3.12 和 uv。长期运行请参考 [Linux 部署指南](docs/web.md#systemd-常驻)；Windows 可运行 CLI 和离线检查。

1. 下载项目并安装锁定版本的依赖：

   ```bash
   git clone https://github.com/MuZiJin701/seu-lecture-reserve-http.git
   cd seu-lecture-reserve-http
   uv sync --locked
   ```

2. 复制 [.env.example](.env.example) 为 `.env`，设置管理员账号和密码：

   ```dotenv
   SEU_WEB_ADMINS='{"admin":"换成你自己的密码"}'
   ```

3. 启动管理台：

   ```bash
   uv run --locked seu-reserve-web
   ```

本机打开 [http://127.0.0.1:8080](http://127.0.0.1:8080)。部署在服务器上时，使用可信网络内可访问的服务器 IP；`0.0.0.0` 只是监听地址。

## 使用

登录管理台 → 新增学校账号 → 选择类别和校区 → 保存 → 点击“启动预约”。需要认证时，在该账号下发送短信并填写六位验证码。

- 关闭网页或退出登录后，任务继续运行；要停止请点击“停止”。
- 运行机器的时钟决定查询阶段、预热、验证码预取和预约时间窗判断。请用 NTP 等方式保持系统时钟同步。验证码预取目标是学校公布的开放时间前 2.7 秒。详见[查询策略](docs/thread-query-strategy.md)。
- 参考目标为有效预约至少八场，其中法律、艺术、心理健康各至少一场。不要求打卡，沙龙不计入；**达标后仍会继续预约**，学校是否认可学分由学校认定。
- 提交后结果不明时，程序会先核对学校记录。不要删除状态文件强行重试；停止或删除本地账号也不会取消学校预约。

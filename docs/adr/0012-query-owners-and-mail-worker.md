# 每账号独立运行，请求由固定线程负责

每个学校账号使用独立进程，隔离认证和故障。账号身份创建后不能修改；同一状态目录只有一个写入者，同一数据根只有一个管理服务。同号会话可以并存，但不同机器或数据根不能协调重复预约，日常应避免多套任务同时预约同号。

2026-11-03 至 11-04 用户确认：普通期和开抢期都保留主线程、独立列表与我的活动查询线程、按需验证码线程，以及可选邮件线程。查询线程各自维护会话和重试；主线程负责认证、使用查询结果、串行提交和保存任务。查询失败时不增加同步兜底请求，避免反复换线程、关连接或重复请求。

验证码线程独占借用主会话取图和 OCR，结束后归还；归还前主线程不能用它认证、提交或复制会话。同一时间最多一个任务或尚未消费的结果，结果带认证代次，旧代次会丢弃。线程通知使用版本和绝对截止时间，避免丢失唤醒；停止时等待在途任务归还，OCR 不能硬中断。

列表线程单独保留最近一次成功快照及其原始时间和版本。查询失败由各自线程重试，HTTP 502–504 的短等待也留在收到该响应的查询线程。主线程在快照有效期内继续筛选和复核，并按尝试额度安排验证码线程重试。待确认的缺席核对仍要求两路新证据。

检查点仍同步保存，诊断日志复用已安全打开的文件，不新增写线程。邮件正文由主线程生成并排队，后台发送不阻塞预约；结果交回主线程保存，退出最多等五秒，未发完的邮件可能中止。

使用者关心的时段、频率和预算见[查询策略](../thread-query-strategy.md)，我的活动刷新与预取取舍见 [ADR-0015](0015-opening-prep-event-history-and-reference-goal.md)。

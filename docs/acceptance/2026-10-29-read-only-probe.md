# 2026-10-29 学校接口只读轮询与校园直连调查

本记录汇总用户授权的学校接口只读对照测试、登录短信验证和无凭据校园直连调查。未提交或取消预约，未发送邮件，未修改 Clash、TUN、系统 DNS 或路由。记录不包含账号、手机号、验证码、Cookie、票据、活动 ID 或活动内容；逐请求耗时仅保存在本机未入库的 `state/diagnostics.jsonl`。

当前行为见[使用指南](../usage.md)，需求见[业务规则](../requirements.md)，首次使用见[README](../../README.md)。

## 测试条件

- 本机 Windows、Python 3.12，代码基线为 `5424823`；测试早于本轮校内 CAS 与刷新提速改动。
- 使用项目 `Client`，经原网关路径完成认证，再复制 Cookie 创建一个独立只读会话。
- 持有任务锁；单会话顺序查询活动列表，不同时运行预约客户端或后台历史刷新线程。
- 使用当时的本机网络配置，没有逐请求抓包验证实际代理出口。
- 北京时间 15:59–16:00 采样；每组约 15 秒，顺序为 0.25 → 0.10 → 0.25 → 0.05 → 0.25 秒，正式对照前有 5 次预热。
- 遇到请求错误即停止，不重试探测限流阈值；本次所有组均完成。

## 无凭据校园直连调查

确认本机连接 `seu-wlan`，并有启用的 Meta TUN 网卡。只读取登录入口的跳转，不发送账号密码、不请求短信：

| 路径 | 观察到的入口跳转 |
| --- | --- |
| 当前默认网络路径；关闭 Python 代理环境读取也一样 | `ehall.seu.edu.cn` → `vpn.seu.edu.cn` |
| 仅给测试连接指定校园 WLAN 网卡，并向校园 DNS 查询真实地址 | `ehall.seu.edu.cn` → `auth.seu.edu.cn`，CAS 服务目标为 `ehall.seu.edu.cn` |

测试连接继续校验 HTTPS 域名证书；没有更改全局网络配置，也没有把指定接口的测试代码加入正式客户端。这个结果说明校园网存在直接进入应用 CAS 的路径，不能证明校内登录一定免短信。
